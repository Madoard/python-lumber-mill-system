# ˚₊‧꒰ა 🌱 Python Lumber Mill System 🌱 ໒꒱‧₊˚

> ✧･ﾟ: *✧･ﾟ:* A command-line Python application that calculates lumber orders based on wood type, log quantity with progressive volume discounts, and shipping methods. *:･ﾟ✧*:･ﾟ✧

‧₊˚ ⋅ ─────────────────────── ⋅ ˚₊‧

## ꒰ 🌷 ꒱ Pricing & Rules

### Wood Types (`per log`)
| 🌿 Code | 🪵 Wood Type | 🎀 Unit Price |
| :---: | :--- | :---: |
| `PIN` | Pine *(Pinho)* | `$ 150.40` |
| `PER` | Peroba | `$ 170.20` |
| `MOG` | Mahogany *(Mogno)* | `$ 190.90` |
| `IPE` | Ipe *(Ipê)* | `$ 210.10` |
| `IMB` | Imbuia | `$ 220.70` |

### Volume Discounts & Shipping
* ₊˚⊹ **Under 100 logs:** No discount (`0%`)
* ₊˚⊹ **100 to 499 logs:** `4%` discount
* ₊˚⊹ **500 to 999 logs:** `9%` discount
* ₊˚⊹ **1,000 to 2,000 logs:** `16%` discount *(orders above 2,000 logs are not accepted)*
* ₊˚⊹ **Shipping Options:** Road (`$ 1,000.00`), Rail (`$ 2,000.00`), or Waterway (`$ 2,500.00`)
